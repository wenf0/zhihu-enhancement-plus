## 商店后台建议填写

### 隐私相关（单选/表单）

- **是否收集用户数据**：可勾选「存储本地设置」类说明，并强调**仅本地**、**不上传服务器**
- **用途**：应用功能（提供扩展设定与词库）
- **是否出售**：否
- **是否用于无关目的**：否
- **隐私政策 URL**（仓库公开后可用）：见 [docs/privacy.md](privacy.md)

```text
https://github.com/wenf0/zhihu-enhancement-plus/blob/main/docs/privacy.md
```

### 权限说明（示例文案）

- **storage**：用于在本地保存开关、屏蔽名单、噪音词库与口味学习数据，不上传。
- **主机权限 \*.zhihu.com**：仅在知乎页面运行内容脚本，实现噪音评分、过滤与阅读增强。

### 单用途说明（示例）

```text
在知乎信息流中进行本地噪音评分与过滤，并提供低干扰阅读增强。
```
